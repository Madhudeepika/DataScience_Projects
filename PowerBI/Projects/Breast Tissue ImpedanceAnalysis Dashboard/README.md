
# 🧪 Breast Tissue Impedance Analysis – Power BI Dashboard

This project explores breast tissue classification using impedance measurements. It uses **Power BI** to visualize and analyze the Kaggle dataset:  
🔗 [Breast Tissue Impedance Dataset](https://www.kaggle.com/datasets/tarktunataalt/breast-tissue-impedance-measurements)

---

## 🎯 Project Goals

- Which tissue type is the most frequent in the dataset?
- How does Max Impedance (Max.IP) vary between tissue types?
- Can tissues be visually classified based on DA and Area values?

---

## 📊 Power BI Dashboard Features

| Visual | Purpose |
|--------|---------|
| ✅ Sample Count by Tissue Type | Understand dataset distribution |
| ✅ Average Max.IP by Tissue | Compare impedance peaks |
| ✅ DA vs Area Scatter Plot | Visualize tissue classification potential |
| ✅ Slicer | Interactive filter by Tissue Type |

📷 _Screenshots of visuals are available in the `Screenshots/` folder._

---

## 🧠 Key Insights

- Tissue types show clear differences in Max.IP
- Visual clustering is visible in DA vs Area scatter
- Dataset supports basic EDA; potential for ML classification in future
